## 2. Model fallback order (fixed before any model is run)

Primary model, as in M2: `correct ~ view + (1 + view | participant) + (1 | item)`.

1. `statsmodels` `BinomialBayesMixedGLM` with a participant intercept, a participant-by-view term and an item intercept (variational Bayes). If it errors or returns non-finite estimates, go to 2.
2. The same model without the participant-by-view term.
3. GEE (binomial, exchangeable, clustered by participant) for the view odds ratio.

Always reported next to the model: the per-participant paired difference with a paired t-test and a Wilcoxon test, and a participant-level bootstrap interval (seed recorded). Statsmodels has no maximum-likelihood GLMM with crossed random effects, so intervals from option 1 or 2 are posterior intervals, not confidence intervals; the report says so.

**Order of use.** The simulator recovery test (a known injected view effect must be recovered) runs before any model is used on real or pilot data. Files marked PILOT get descriptive output only; the scripts switch inference off for them.
